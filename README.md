# AI-Powered Data Cleaning Assistant

An automated data cleaning tool that detects and fixes common data quality issues — missing values, duplicates, and inconsistent formatting — using Python and AI-assisted suggestions.

## Features
- Auto-detects data quality issues (missing values, duplicates, formatting inconsistencies)
- Auto-detects CSV encoding for smoother file handling
- AI-generated suggestions for cleaning steps using OpenAI/GPT models
- Simple, reusable utility functions for common cleaning tasks

## Tech Stack
- Python
- OpenAI API (GPT models) for AI-based suggestions
- Pandas for data processing

## Files
- `app.py` — main application entry point
- `data_cleaning.py` — core data cleaning logic
- `ai_suggestions.py` — AI-powered cleaning suggestions
- `utils.py` — helper functions

## How to Run
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
